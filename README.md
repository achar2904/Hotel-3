## 🌟 ภาพรวมระบบ (Overview)

**Hotel 3** เป็นระบบบริหารจัดการการแจ้งซ่อม บริการห้องพัก และประสานงานข้ามแผนกในโรงแรมแบบ Real-Time เชื่อมโยง 4 แผนกหลัก ได้แก่:
- 🛎️ **Front Office (ฟร้อนท์):** รับเรื่องจากแขก แจ้งเหตุ ประสานงานด่วน
- 🧹 **Housekeeping (แม่บ้าน):** ทำความสะอาดห้องพัก ตรวจเช็กสิ่งอำนวยความสะดวก
- 🔧 **Engineering (ช่าง):** งานระบบ แอร์ ประปา ไฟฟ้า ซ่อมบำรุง
- 💻 **IT Support (ไอที):** ระบบอินเทอร์เน็ต Wi-Fi, ทีวี, โทรศัพท์, และคีย์การ์ด

ระบบทำงานด้วย **Node.js (Native HTTP Backend)** ประสานงานกับฐานข้อมูล **MySQL (`hotel_case_db`)** โดยไม่มีการใช้เฟรมเวิร์กขนาดใหญ่ที่ซับซ้อน ทำให้มีประสิทธิภาพสูง โหลดเร็ว ปลอดภัย และดูแลรักษาง่าย

## 🚀 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. 🛡️ ความปลอดภัยและระบบป้องกันระดับสูง (Security & Route Guards)
- **Unified Single-Entry Login Gateway:** ทางเข้าสู่ระบบศูนย์กลางทางเดียวที่หน้าแรก (`/`)
- **Server-Side Route Guards:** ป้องกันการลักไก่พิมพ์ URL เช่น `/admin` หรือ `/user` ตรง ๆ หากไม่มี Session Token ที่ถูกต้อง ระบบจะดีดกลับไปหน้าล็อกอินพร้อมแจ้งเตือนทันที
- **Strict RBAC:** แบ่งแยกสิทธิ์เด็ดขาดระหว่าง `ADMIN`, `OWNER`, `DEPT_HEAD`, และ `STAFF`

### 2. 📱 ระบบพนักงานหน้างาน (Field Staff Portal — `/user`)
- **สร้างเคสใหม่ได้รวดเร็ว:** เลือกจุดเกิดเหตุ, พิมพ์เลขห้องจากคีย์แพดด่วน, เลือกอาการปัญหาด้วย Smart Chips
- **คิวงานและจัดการสถานะเคส:** รับงาน (Take Job), พักงานรออะไหล่ (Pause), ปิดงานพร้อมสรุปการแก้ไข (Close)
- **โอนย้ายงานข้ามแผนก (Case Transfer):** ส่งต่องานไปแผนกอื่นพร้อมระบุเหตุผล มีปุ่มปิดหน้าต่างสีแดงมุมขวาบนเพื่อความสะดวกในการใช้งาน
- **Header Profile แบบ Dropdown:** แสดงชื่อและแผนก รองรับการแสดงผลหน้าจอมือถืออย่างสวยงาม

### 3. 👑 ศูนย์ควบคุมผู้บริหารและแอดมิน (Admin & Owner Portal — `/admin`)
- **Master All-Cases Table:** แสดงเคสทั้งหมด ค้นหา กรองตามแผนก สลับแผนกปลายทาง (Re-route) หรือสั่งบังคับปิดเคส (Force Close)
- **Daily Departmental KPI Dashboard:** สถิติสรุปภาพรวมรายวันแยก 4 แผนก (เคสทั้งหมด, กำลังทำ, ปิดสำเร็จ, อัตราความสำเร็จ)
- **422 Live Rooms Inventory:** ผังห้องพัก 422 ห้อง (ชั้น 1–5) กรองตามชั้นและสถานะ คลิกดูประวัติเคสย้อนหลังของห้อง และสั่งเปลี่ยนสถานะห้องพักลง MySQL ได้ทันที
- **Staff Workload Tracker:** ติดตามภาระงานบุคลากรรายบุคคลแบบสด ๆ
- **User & Access Management:** ระบบจัดการผู้ใช้งาน เพิ่มพนักงานใหม่ แก้ไขสิทธิ์ Role แผนก และรีเซ็ตรหัสผ่าน PIN 6 หลัก

### 4. 🎨 ดีไซน์ระดับมืออาชีพ (Clean & Minimalist Design)
- ออกแบบโทนสีหรูหรา Professional Slate (`#334155`)
- รองรับฟอนต์ **Sarabun** สำหรับภาษาไทย และ **Plus Jakarta Sans** สำหรับตัวเลขและภาษาอังกฤษ
- ดีไซน์สะอาดตา เรียบหรู ตัดไอคอนรบกวนสายตาออกเพื่อความเป็นผู้ใหญ่ตามมาตรฐานโรงแรมระดับ 5 ดาว

## 🗄️ ฐานข้อมูลและการติดตั้ง (Database & Installation)

### 1. ความต้องการของระบบ (Prerequisites)
- **Node.js:** v16.0.0 ขึ้นไป
- **MySQL Server:** v5.7 หรือ v8.0+ (พอร์ตมาตรฐาน 3306)

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. ติดตั้งฐานข้อมูลและนำเข้าข้อมูลตั้งต้น
เปิดใช้งาน MySQL daemon จากนั้นรันคำสั่ง:
```bash
npm run seed
```
*(สคริปต์จะสร้างฐานข้อมูล `hotel_case_db`, สร้างตารางทั้งหมด, สร้างผู้ใช้ตัวอย่าง 4 แผนก + ผู้บริหาร และสร้างผังห้องพัก 422 ห้องอัตโนมัติ)*

## 📡 เอกสาร API (API Reference)

| Method | Endpoint | สิทธิ์ที่อนุญาต | รายละเอียด |
|:---:|---|:---:|---|
| `POST` | `/api/login` | สาธารณะ | ตรวจสอบรหัสพนักงานและ PIN 6 หลักเพื่อออก Session Cookie |
| `POST` | `/api/logout` | ผู้ใช้ที่ล็อกอิน | ยกเลิก Session และออกจากระบบ |
| `GET` | `/api/me` | ผู้ใช้ที่ล็อกอิน | ขอข้อมูลผู้ใช้งานปัจจุบันและสิทธิ์สังกัด |
| `GET` | `/api/cases` | ผู้ใช้ที่ล็อกอิน | ดึงรายการเคส (พนักงานเห็นเฉพาะแผนกตนเอง, Admin/Owner เห็นทั้งหมด) |
| `POST` | `/api/cases` | Staff, Head, Admin | บันทึกการแจ้งเคสปัญหาใหม่ลง MySQL |
| `POST` | `/api/cases/action` | Staff, Head, Admin | เปลี่ยนสถานะเคส (รับงาน / พักงาน / ปิดงาน) |
| `POST` | `/api/cases/transfer`| Staff, Head, Admin | ส่งต่องานข้ามแผนกพร้อมบันทึกประวัติการโอนย้าย |
| `POST` | `/api/cases/reroute` | Admin | คำสั่ง Admin บังคับสลับแผนกปลายทาง |
| `POST` | `/api/cases/force-close` | Admin | คำสั่ง Admin บังคับปิดเคสในระบบ |
| `GET` | `/api/rooms` | ผู้ใช้ที่ล็อกอิน | ดึงข้อมูลผังห้องพักทั้ง 422 ห้อง |
| `POST` | `/api/rooms/status` | Admin | เปลี่ยนสถานะห้องพัก (`AVAILABLE` / `MAINTENANCE`) พร้อมระบุเหตุผล |
| `GET` | `/api/stats/daily` | Admin, Owner | ดึงสรุปสถิติผลการปฏิบัติงาน 4 แผนกประจำวัน |
| `GET` | `/api/staff` | Admin, Owner | ติดตามภาระงานพนักงานรายบุคคล |
| `GET` | `/api/users` | Admin, Owner | ดึงรายชื่อบัญชีผู้ใช้งานทั้งหมด |
| `POST` | `/api/users` | Admin | เพิ่มบัญชีผู้ใช้งานใหม่ลงฐานข้อมูล |
| `POST` | `/api/users/update` | Admin | แก้ไขข้อมูล แผนก ระดับสิทธิ์ และสถานะบัญชี |
| `POST` | `/api/users/reset-pin` | Admin | รีเซ็ตรหัสผ่าน PIN 6 หลักให้พนักงาน |
